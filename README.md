# Football Management System

A beginner-friendly football management system built with Go.

## About the Project

The Football Management System is a console-based Go application designed to manage football players and perform different operations on player information.

This project was created as part of my journey learning Go programming and practicing fundamental programming concepts such as structs, slices, functions, loops, conditionals, searching, sorting, and data management.

## Features

* Add a new player
* View player information
* Search for a player
* Update player information
* Remove a player
* Transfer players
* Sort players
* View player rankings
* View statistics
* Manage players through a menu-driven interface

## Technologies Used

* Go (Golang)
* Git
* GitHub

## How to Run

Make sure Go is installed on your computer.

Clone the repository:

```bash
git clone https://github.com/johnogah501-tech/Football-Management-System.git
```

Navigate into the project:

```bash
cd Football-Management-System
```

Run the application:

```bash
go run .
```
